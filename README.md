# dotnet-interview

.NET Junior / Mid / Senior seviye mülakat hazırlığı için kapsamlı bir çalışma reposu.

**İçerik:**
- .NET / C#
- Relational databases, SQL Server, PostgreSQL, MongoDB
- Docker & container ekosistemi
- Azure Cloud
- AI Engineering (.NET tarafında — Semantic Kernel, OpenAI, RAG, ML.NET)
- Sistem tasarımı ve mimari
- Mülakat süreci ve soft skills

## Nereden başlamalıyım?

Önce **[ROADMAP.md](./ROADMAP.md)** dosyasını okuyun. Bu, tüm çalışma planının haritasıdır.

Her konu için:
1. Kavramsal `README.md` (teori + mülakat perspektifi)
2. Çalıştırılabilir kod örnekleri (`src/` altında `dotnet run` ile çalışan projeler)
3. `interview-questions.md` (o konudan çıkabilecek mülakat soruları)

## Repo Yapısı

Detaylı yapı için [ROADMAP.md](./ROADMAP.md#repo-yapısı) bölümüne bakın.

```
01-junior/    → Junior seviye konular
02-mid/       → Mid seviye konular
03-senior/    → Senior seviye konular
04-databases/ → Veritabanları (SQL / NoSQL)
05-docker/    → Container / Docker / K8s
06-azure/     → Azure Cloud servisleri
07-ai/        → AI Engineering (.NET)
08-system-design/  → Sistem tasarımı
09-interview/ → Mülakat pratikleri
```

## Kullanım

Her klasörün altındaki `src/` içine girip:

```bash
dotnet run
```

komutuyla o konunun kod örneğini çalıştırabilirsiniz.
